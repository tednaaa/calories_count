# Calories Count — техническое задание

Персональный счётчик калорий. PWA, работает офлайн, устанавливается на Android и iPhone.

## Идея в одном абзаце

Каталог блюд ведётся вручную **прямо в этом репозитории**: приготовил еду → сфотографировал → положил фото и калорийность в код → закоммитил. Приложение показывает этот каталог сеткой фотографий, из которой в два тапа собирается приём пищи. Всё, что съедено, и результат калькуляции нормы хранятся локально в IndexedDB на устройстве.

## Основной сценарий дня

1. Проснулся, выпил кофе с шоколадкой → открыл приложение → тапнул «Кофе» и «Шоколад» → «Подтвердить».
2. Съел два варёных яйца → тапнул «Яйцо варёное», выставил ×2 → «Подтвердить».
3. Пообедал рисом с мясом → тапнул «Рис с говядиной» → «Подтвердить».
4. В любой момент на главной видно: съедено сегодня, сколько осталось до цели, как идёт неделя.

## Принципы

**Офлайн-первый.** Никакого бэкенда, никакой авторизации, никаких сетевых запросов в рантайме. После установки приложение полностью работоспособно в самолёте.

**Каталог — это код.** Блюда не создаются из интерфейса. Единственный способ добавить блюдо — коммит в репозиторий. Это осознанное ограничение: каталог получает ревью, типизацию и историю изменений, а приложение остаётся read-only относительно контента.

**Дневник — это личные данные устройства.** Никогда не покидают телефон. Синхронизации между устройствами нет by design: два телефона — два независимых дневника.

**Никаких лишних чисел.** Считаем только калории. Ни БЖУ, ни граммы, ни микронутриенты. Каждое лишнее поле — это лишняя работа при каждом коммите блюда, и именно на этом такие трекеры и умирают.

## Границы (чего в проекте нет)

| Нет | Почему |
|---|---|
| Бэкенда, аккаунтов, синхронизации | Один пользователь, один телефон-основной. Страховка — экспорт JSON |
| Добавления блюд из интерфейса | Обсуждалось и отклонено: размывает каталог, ломает дисциплину коммитов |
| Граммовок и веса порций | Порция — единица учёта. Домашняя еда всё равно оценивается на глаз |
| БЖУ | Отложено. Поля зарезервированы в типах, включается позже без миграций |
| Разметки на завтрак/обед/ужин | Плоская лента по времени |
| Штрихкодов, внешних баз продуктов | Требуют сети и не покрывают домашнюю готовку |
| Графика веса | Отложено до покупки весов. История пишется с первого дня |
