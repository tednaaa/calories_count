# 07 — Порядок реализации

Этапы выстроены так, чтобы приложением можно было начать пользоваться как можно раньше, а не после того, как готово всё.

## Этап 0 — Скелет

Vite + Vue 3 + TypeScript + Tailwind + vue-router. Devenv. Пустые вьюхи, нижняя навигация, `vite-plugin-pwa` в минимальной конфигурации.

**Готово, когда:** `npm run dev` открывает приложение, переключение по вкладкам работает.

## Этап 1 — Данные и каталог

- `src/data/foods.ts`, `src/data/categories.ts`, типы `Food`, `CategoryId`.
- `src/db/` — Dexie, схема версии 1, типы `Entry`, `Profile`, `WeightRecord`.
- `src/composables/useLiveQuery.ts`.
- `src/domain/date.ts` — `toDateKey` и границы недели.
- `scripts/optimize-foods.mjs` + `npm run foods:optimize`.
- `src/data/foods.spec.ts` — тест целостности каталога.
- Первые 10–15 блюд с реальными фото: то, что реально ешь каждый день.

**Готово, когда:** каталог отображается тестовым списком, тесты целостности проходят.

## Этап 2 — Калькулятор и онбординг

- `src/domain/calories.ts` с юнит-тестами на формулу и нижнюю границу.
- `OnboardingView` с живым расчётом.
- Гард роутера по наличию профиля.

**Готово, когда:** первый запуск приводит к сохранённому профилю с нормой.

## Этап 3 — Экран «Сегодня»

Кольцо прогресса, лента дня, редактирование количества, удаление с отменой, переключение на прошлые дни, пустое состояние.

На этом этапе записи ещё нечем создавать — проверяется на данных, засеянных из консоли.

## Этап 4 — Экран «Добавить»

Поиск, чипсы категорий, блок «Часто», сетка карточек, корзина со степперами, подтверждение. Поддержка `?date=` для добавления задним числом.

**Готово, когда:** приложением можно пользоваться по назначению. С этого момента — ежедневная эксплуатация, дальнейшие этапы уже поверх живых данных.

## Этап 5 — Статистика

Диаграмма за 7 дней с линией цели, сводка, переход на день по тапу.

## Этап 6 — Настройки и экспорт

Редактирование профиля с пересчётом, ручное переопределение нормы, экспорт и импорт JSON, блок «О приложении», инструкция по установке на iPhone.

Экспорт стоит сделать сразу после этапа 4 и не откладывать: до него единственная копия данных существует в одном экземпляре на телефоне.

## Этап 7 — PWA и деплой

Полный манифест, иконки (192, 512, maskable, apple-touch), мета-теги iOS, прекэш с фотографиями, `navigator.storage.persist()`, `_redirects`, `.gitlab-ci.yml`, кастомный домен, чек-лист из [06-pwa-deploy.md](06-pwa-deploy.md).

**Готово, когда:** приложение установлено на оба телефона и работает в офлайне.

## Дальше, по мере надобности

| Что | Когда осмысленно |
|---|---|
| График веса | После покупки весов. Данные к этому моменту уже накоплены |
| БЖУ | Если появятся силовые тренировки. Включается без миграции — см. [02-data-model.md](02-data-model.md) |
| Месячная статистика | Когда накопится 4–6 недель истории |
| «Повторить вчерашний день» | Если обнаружится, что дни часто повторяются целиком |
| Vue Vapor Mode | Когда Vue 3.6 выйдет из беты. Включается покомпонентно |

## Порядок, которого стоит держаться

Этапы 1 → 2 → 3 → 4 последовательны: каждый опирается на предыдущий. Этапы 5, 6, 7 независимы друг от друга, и их можно делать в любом порядке — но экспорт (часть этапа 6) не стоит откладывать после начала реальной эксплуатации.
